2. Complete Onboarding Procedure

1
Create Tenant Shell in Admin Dashboard

Open index.html, input the restaurant name and WooCommerce URL, then click Provision Tenant Shell.

Copy the generated Client Access Key (Tenant ID) from the directory list.

2
Inject Encrypted Credentials in Client Portal

Open client.html, log in using the Tenant ID, paste the client's WooCommerce Secret & Foodics Bearer Token into the secure fields, and click Encrypt & Save Credentials.

3
Configure WooCommerce Webhook Listener

Log into the restaurant's WordPress Dashboard and navigate to:

WooCommerce ➔ Settings ➔ Advanced ➔ Webhooks ➔ Add Webhook
  • Name: Foodics Sync Order Created
  • Status: Active
  • Topic: Order Created
  • Delivery URL: Paste the exact Webhook Endpoint from client.html (e.g. https://your-domain.com/api/Webhooks/woocommerce/order-created/{tenantId})
  • Secret: Paste the exact Webhook Secret configured in step 2.
  • API Version: WP REST API Integration v3
4
Run Verification Order

Either place a live test order on WooCommerce or use section 3 in index.html to trigger an order simulation. Verify that the terminal logs record a green Success entry.

3. Troubleshooting Matrix

Error SignatureRoot CauseImmediate Solution
401 Unauthenticated Foodics JWT Bearer Token is expired or invalid. Generate a fresh Bearer Token in Foodics Console and re-save via client.html.
Padding is invalid Mismatch in AES Master Encryption keys. Ensure EncryptionService.cs uses matching password/salt settings. Re-save keys in portal.
Not a valid Base-64 string Raw unencrypted credentials stored directly in database. Use client.html form to force execution of the controller's AES encryptor.
Foodics API Error (400) Invalid SKU or Product ID in test payload. Ensure Product ID in WooCommerce payload exists in Foodics sandbox inventory.
