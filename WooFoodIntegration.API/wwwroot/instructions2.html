Setup Manual

WooCommerce ➔ Foodics Integration

Complete step-by-step instructions for linking orders and syncing inventory.

Read Before Starting

Follow these steps exactly in order. Do not skip any fields. If you do not have a Client Access Key, request one from your system administrator before proceeding.

1

Collect Required Credentials

Before doing anything, gather the following 4 pieces of information from the restaurant:

  • Restaurant Name: e.g., Burger House
  • WooCommerce Base URL: Their website link (e.g., https://burgerhouse.com)
  • Foodics API Domain: E.g., https://api-sandbox.foodics.com or the live API URL.
  • Foodics Bearer Token: The long JWT key starting with eyJ... (generated from their Foodics Developer settings).
2

Save Credentials in the Portal

Log into your Client Portal using your Client Access Key, then configure the system:

  1. Fill in the Restaurant Name, WooCommerce URL, and Foodics URL.
  2. Paste the Foodics Bearer Token into the exact field designated for it.
  3. Create your own secure Webhook Secret (write it down or generate a random string like secret123456) and paste it into the Webhook Secret field.
  4. Click Encrypt & Save Settings.
3

Copy Your Webhook URL

On the bottom left of your Client Portal, you will see your unique Webhook Endpoint URL displayed like this:

https://your-domain.com/api/Webhooks/woocommerce/order-created/{your-tenant-id}

Click the Copy Webhook Link button. You will need to paste this URL into WordPress twice in the next steps.

4

Setup Webhook 1: Order Creation

Log into the restaurant's WordPress Dashboard and navigate to:

WooCommerce ➔ Settings ➔ Advanced ➔ Webhooks ➔ Add Webhook
  • Name: Foodics Order Sync
  • Status: Select Active
  • Topic: Select Order Created
  • Delivery URL: Paste the Webhook URL you copied in Step 3.
  • Secret: Paste the Webhook Secret you created in Step 2.
  • API Version: Select WP REST API Integration v3
5

Setup Webhook 2: Inventory Returns / Refunds

To ensure inventory syncs correctly when an order is cancelled or refunded, create a second webhook in WooCommerce:

WooCommerce ➔ Settings ➔ Advanced ➔ Webhooks ➔ Add Webhook
  • Name: Foodics Stock Update (Returns)
  • Status: Select Active
  • Topic: Select Order Updated
  • Delivery URL: Paste the same Webhook URL from Step 3, but change order-created to order-updated at the end.
  • Secret: Paste the same Webhook Secret you created in Step 2.
  • API Version: Select WP REST API Integration v3
6

Verify Live Traffic & Automated Stock Sync

Go back to your Client Portal and look at the "Live Traffic & Order Logs" terminal on the right.

1. Stock Sync: Your system runs an automated background task to sync Foodics inventory to WooCommerce. Wait a few minutes and watch for this green log to confirm inventory is flowing:

[StockSync] Success: WooCommerce stock updated for product XYZ

2. Order Sync: Place a test order on the WooCommerce website. You should instantly see this log confirm the connection:

[OrderCreated] Success: Foodics order created successfully.
